# VerifyIT: AI-Driven IT Credibility Analyzer

An intelligent system designed to detect and verify IT-related misinformation using DistilBERT for classification and automated evidence retrieval.

## Key Features
- **IT Domain Validation:** Filters out non-technical claims.
- **Credibility Assessment:** Classifies claims as Credible, Questionable, or Misleading.
- **Evidence Retrieval:** Sources data from MDN, IETF, W3C, and OWASP.
- **Explainable AI (XAI):** Highlights technical terms influencing the verdict.

## Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** FastAPI (Python)
- **Database:** MongoDB Atlas
- **ML Model:** DistilBERT
